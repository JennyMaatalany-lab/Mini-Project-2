# Mini-Project-2
USEK - IT Workshop 1 - Mini Project 2

-- This a small business called Cedarline Supply Co., following the MVC structure from our Lecture 4. Everything is in memory with ObservableList stores and no database.

-- Login: a small window with your four hardcoded accounts (HR2000/2000HR, OD3000/3000OD, INV1000/1000INV, CL4000/4000CL). ! The username isn’t case sensitive; the password is. !

-- Home: four cards (HR, Clients, Inventory, Orders) that each open their own window. The card for the signed-in user’s department is outlined, and there’s a Log out button.

-- Each department window: a form on the left, a TableView on the right, and Insert / Update / Delete / Clear buttons. Clicking a row fills the form for editing. The forms validate input (numbers, dates, email, phone).
